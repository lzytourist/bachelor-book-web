# Bachelor Book — Web (Static Site)

Static site for **Bachelor Book** (`app.bachelorbook`) hosted on GitHub Pages: landing page, Privacy Policy, Terms of Service, and Account Deletion Guide (required for Google Play Console Data Safety).

## Files

- `index.html` — marketing landing page
- `privacy.html` — Privacy Policy (discloses Google Sign-In, FCM, Camera/QR, AdMob, and in-app Account Deletion)
- `terms.html` — Terms of Service
- `delete-account.html` — Google Play Store Account Deletion Guide
- `logo.svg` — Charcoal + Teal Bachelor Book brand mark
- `.nojekyll` — serves static files directly on GitHub Pages

## Live GitHub Pages URLs

- **Landing:** `https://lzytourist.github.io/bachelor-book-web/`
- **Privacy Policy (Play Console):** `https://lzytourist.github.io/bachelor-book-web/privacy.html`
- **Terms of Service:** `https://lzytourist.github.io/bachelor-book-web/terms.html`
- **Account Deletion URL (Play Console Data Safety):** `https://lzytourist.github.io/bachelor-book-web/delete-account.html`
